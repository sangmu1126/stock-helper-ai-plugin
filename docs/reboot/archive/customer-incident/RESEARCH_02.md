# 고객 문제 후보 재조사

조사 기준일: 2026-11-18 (Asia/Seoul)  
상태: 후보 비교와 우선 검증 대상 제안. 최종 주제·신규 스펙은 아직 확정하지 않음.

## 1. 이번 선정 기준

1. 고객의 실제 상황이 회사 공지의 실제 제보 사례 또는 구체적 보도로 확인되는가.
2. 플러그인의 출력이 바로 그 고객의 어려움을 줄이는가.
3. 이미 제공되는 서비스와 비교할 때 새 도구의 역할이 설명되는가.
4. 일반 대화 응답보다 파일 대조·계산·반복 검증이 유용한가.
5. 공개 자료와 합성 입력으로 과장 없이 시연 가능한가.

일반적 위험, 복잡한 규정, FAQ 존재만으로 고객 피해의 발생을 주장하지 않는다. 문제의 존재, 해결 기능의 타당성, 실제 사용 의사는 따로 평가한다.

## 3. 우선 검증 후보: 배당세 정산 내역 도우미

### 고객 문제

**미국 ETF·리츠 배당세가 나중에 정산될 때, 고객은 달러 입금과 원화 출금이 함께 생긴 이유와 원화 잔액 부족 여부를 자신의 내역에서 이해하기 어렵다.**

이 문장 중 정산 구조와 잔액 부족 가능성은 공식 확인 사항이다. 실제 이해의 어려움과 도구 효과는 아래 보도 검증·고객 관찰로 보강해야 한다.

### A1. 카카오페이증권 공식 공지

- 제목: 해외주식 소득재분류 안내(8/24)
- 게시: 2026-08-24
- [원문](https://www.kakaopaysec.com/customer/notice/dynamicBoardPageDetail.do?id=7434)
- 확인 수준: 웹 본문 직접 열람

회사는 달러 입금과 원화 출금이 같이 발생할 수 있고, 배당 지급일마다 여러 건이 처리될 수 있다고 설명한다. 원화 잔액이 부족하면 미수금이 생길 수 있으며 이미 해지한 계좌도 대상이 될 수 있다고 안내한다. 공지는 해당 정산을 시스템 오류가 아닌 정상 절차라고 설명한다.

이는 원화 잔액과 달러 자산을 구분해서 확인해야 하는 이유의 근거다. 개별 거래의 정당성이나 계산 정확성까지 이 공지만으로 확정하지 않는다.

- 매체: 녹색경제신문
- 제목: 잔고 0원 계좌에 날아든 마이너스 고지서…미국 ETF '소득 재분류'의 덫
- 날짜: 검색 색인상 2026-08-27

색인에는 거래를 중단한 계좌의 미수 통보와 고객 사례가 나온다. 구체적 수치·인과관계·회사 반론을 전문 검증했다고 주장하지 않는다. 제출의 핵심 사례로 쓰기 전 접근 가능한 전문이나 독립된 추가 보도를 확보해야 한다.

### 제안할 최소 시연

입력은 마스킹한 내역 CSV, 원화 기초 잔액, 공식 공지 요약이다. 데이터는 합성으로 표시한다.

1. USD 환급과 KRW 세금 출금을 각 통화 원장으로 분리한다.
2. 명시적 정산 ID가 있는 행만 묶고, 나머지는 미연결로 남긴다.
3. 원화 기초 잔액과 해당 기간 전체 원화 거래가 주어졌을 때 잔액 변화를 재현한다.
4. 재현한 원화 음수 잔액과 앱의 실제 미수금 판정을 구분한다.
5. 결과 표의 각 숫자를 입력 행으로 추적하고 고객이 읽을 설명을 붙인다.

내역이 불완전하면 잔액 부족액을 확정하지 않는다. 달러와 원화를 임의 환율로 합쳐 채무가 해소됐다고 말하지 않는다. 세법 자체를 바꾸거나 납부 의무를 없애는 기능은 아니다.

### 기존 해결 수단과 미확인 영역

회사는 이미 공식 설명과 대상 종목 파일을 제공한다. 따라서 공지를 다시 요약하는 것만으로는 차별화가 약하다. 후보의 역할은 고객 개인 내역의 통화별 대조다.

앱이 같은 수준의 개인별 연결 설명을 이미 제공하는지는 아직 확인하지 못했다. 공식 CSV 내보내기 지원과 실제 열 구조도 미확인이다. 고객이 화면 값을 옮겨야 한다면 입력 부담이 효과보다 커질 수 있다. 이 두 항목을 구현 전 우선 확인한다.

세무 자문·납부액 산정 대신 고객이 제공한 확정 거래의 재구성과 설명으로 MVP 범위를 제한한다. 사전 세액 예측은 운용사 자료·세율·환율 근거가 추가로 필요하므로 별도 범위다.

### 제안 기능과 경쟁 상황

고객이 받은 마스킹 메시지에서 입금 요청·신분정보 요구·앱 설치 요청을 추출하고, 공식 경보와 같은 지점을 문장 단위로 표시할 수 있다. 불일치를 경고할 뿐 직원 신원·사기 여부를 최종 인증하지 않는다. 경고가 없다고 안전 판정을 내리지 않는다.

그러나 유사 서비스가 이미 있다.

- [카카오페이 공식 블로그](https://story.kakaopay.com/57-kakaopay-secure/), 2022-09-26: 사기 이력 탐지·악성 앱 탐지 기능 설명.
- [KISA 보도자료](https://www.kisa.kr/402/form?lang_type=KO&page=1&postSeq=2559), 2025-12-03: 카카오뱅크 AI 스미싱 확인 서비스와 문자·메신저 분석 연계 설명.

이는 경쟁 비교 자료이며 카카오뱅크를 제출 대상에 추가한다는 뜻이 아니다. “메신저도 분석한다”는 이유만으로 기존 서비스에 없는 기능이라고 주장할 수 없다. 설치된 금융앱보다 Codex를 쓰는 이점이 아직 약하므로 현재 차순위다.

## 6. 기존 후보보다 나아진 점

기존 후보는 장애가 발생했다는 근거에서 문의서 작성의 어려움으로 건너뛰었다. 새 우선 후보는 공식적으로 안내된 통화별 입출금·원화 부족 현상을 그대로 계산·설명의 대상으로 삼는다.

다만 다음을 아직 달성했다고 말할 수는 없다.

- 모든 정산 내역의 자동 연결과 세액 검증.
- 앱보다 더 나은 개인별 설명 제공.
- 실제 고객의 입력 가능성·Codex 사용성.
- 403 기사 전문 확인과 복수 사례 검증.
